# Calculator Console App

A simple console-based calculator built in C# as part of a learning project. The app is developed feature-by-feature using Git branches, with each operation implemented and merged incrementally.

## Features

- **Addition** — Add two numbers
- **Subtraction** — Subtract two numbers
- **Multiplication** — Multiply two numbers
- **Division** — Divide two numbers, with divide-by-zero handling
- **Continuous Calculation** — Perform multiple calculations in one session without restarting the app

## How It Works

1. Run the application.
2. Enter the required numbers when prompted.
3. View the result printed to the console.
4. Choose whether to perform another calculation or exit.

## Built With

- C#
- .NET Console Application

## Project Structure

- `Program.cs` — Contains the main program logic and calculator operations

## Branching Strategy

Each feature is developed on its own branch (e.g., `feature/addition`, `feature/subtraction`) and merged into the `assignment-1-2`
